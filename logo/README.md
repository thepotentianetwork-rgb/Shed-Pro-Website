# ShedPro Studio logo

| file | what it is | where it is used |
|---|---|---|
| `mark.svg` | the mark on its own, 60x60 | reference art; the header draws its own inline copy |
| `lockup-dark-bg.svg` | mark + wordmark, white "SHED" | dark backgrounds |
| `lockup-light-bg.svg` | mark + wordmark, near-black "SHED" | light backgrounds |
| `favicon.svg` | 16px-legible variant on a dark chip | `designer.html` tab icon |

## The wordmarks are outlines, not text

Both lockups carry the wordmark as **paths**, generated by `outline_lockup.py`
from Barlow Condensed 900 (SHEDPRO) and 700 (STUDIO).

They were originally `<text font-family="'Barlow Condensed'...">` with no
embedded font. An SVG loaded as an `<img>`, used as a favicon, or opened in
Canva / Illustrator / Figma is its own document and cannot borrow a font from
the page around it — so anywhere Barlow Condensed was not installed, the
letters reshaped into whatever that machine had. Outlines say the same thing
everywhere, at the cost of ~7 KB a file.

Consequence: **the wordmark is no longer editable as text.** To change the
words, the size, the tracking or the weight, edit `outline_lockup.py` and
re-run it — do not hand-edit the path data.

```
cd logo && python3 outline_lockup.py     # needs fontTools + the Barlow Condensed TTFs
```

The TTFs are not committed here. Barlow Condensed is Open Font License; fetch
900 and 700 from Google Fonts and drop them beside the script as
`BarlowCondensed-900.ttf` and `BarlowCondensed-700.ttf`.

## The favicon is a variant, not the mark scaled down

At 16px the mark's 3px strokes fall below one device pixel and its dimension
ticks disappear. `favicon.svg` drops the ticks and the vertical dimension line,
thickens what is left, centres it (the mark sits high in its own box) and adds
a dark rounded chip so it holds up on light browser chrome as well as dark.
